# RAG — KB Indexing

## Masalah / Kebutuhan

CRUD FAQ harus memicu indexing Pinecone secara async dengan transactional outbox.

## Perubahan

- `kb/kb.go` — tx + outbox pada Create/Update/Delete
- Pub/Sub `retrieval-index` + worker
- `POST /api/v1/knowledge-base/reindex` — backfill batch

## File utama
