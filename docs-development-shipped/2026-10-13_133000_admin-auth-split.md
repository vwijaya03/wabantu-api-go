# Login platform-admin terpisah + hardening bootstrap

**Tanggal:** 2026-10-13  
**PR:** (draft, stacked di atas `be/h1-llm-master`)  
**Tipe:** feat/security  
**Status:** Branch `be/admin-auth` (belum merge)

## Masalah / Kebutuhan
Super admin login lewat endpoint client dengan sesi 7 hari yang sama; `/admin/*` hanya cek role;
bootstrap memakai compare string biasa dan bisa diulang; tidak ada lockout/audit login.

## Perubahan
- `POST /api/v1/platform-admin/login` → `{accessToken, expiresAt}`; sesi `kind:admin` 2 jam absolut, JWT `typ:admin` 60 m.
- Client login menolak super_admin (pesan generik); admin login menolak client.
- Middleware `SessionKind`: `/admin/*` + `tag:super_admin` hanya token admin; token admin ditolak di endpoint tenant.
- Impersonate menerbitkan token `typ:impersonation` 30 m, ditolak di `/admin/*`; audit admin+tenant.
- Lockout per akun+IP / IP / akun, rate limit per IP & akun, hash dummy bcrypt asli.
- Tabel audit `auth_login_attempt` (system migration 28).
- Bootstrap: secret baru `PlatformAdminBootstrapKey`, constant-time, 403 bila kosong/pendek, satu kali dalam transaksi (advisory lock), rate limit + audit, tidak menerbitkan token.
- `audit/logs` dan `flags` (kecuali `flags/check`) ber-`tag:super_admin`.

Detail: [docs/ADMIN_AUTH.md](../docs/ADMIN_AUTH.md).
